禁地兵装：优雷卡武器

heading.anchorLabel

到了优雷卡也仍要感受光头的支配，当然还有他的徒弟们。

要点：

  • 优雷卡是 4.0 时期的特殊游戏内容，所有的技能会被同步到 70 级（70 级以后的技能、特性无法使用）。后文默认玩家已经有对应的优雷卡元素等级，并已经完成了相关剧情任务，若不了解优雷卡的基础情况，可查看这个页面了解优雷卡的信息和升级方式。
  • 在升级阶段也尽可能积极参加优雷卡内的 NM 击杀，武器升级需要大量 NM 掉落的水晶。
  • 70 级校服升级改良也在优雷卡中（仅限常风之地），完成升级后的校服可染色。
  • 刷怪时务必记得调整魔素板（可用 /魔素板攻势 或 /魔素板守势 宏）。

制作进度、材料追踪表

常风之地

heading.anchorLabel

随着元素等级提升，据点内可露儿会出现新的剧情任务，随着剧情任务推进，盖罗尔特也要开始折磨帮助大家强化装备了。玩家需要提供 70 级旧化的 xx 校服装备（如果丢失可以去主城失物管理员处购买）和常风之地的乱属性水晶。

禁地兵装 +1
340		乱属性水晶 x 400（武器）/ 150（装备）
禁地兵装 +2
345		乱属性水晶 x 800（武器）/ 400（装备）
常风装备
350/355		帕祖祖的羽毛 x 3（武器） /常风水晶 x 150（装备）

常风合计：乱属性水晶 x 1300 + 帕祖祖的羽毛 x 3（武器） / 乱属性水晶 x 600 + 常风水晶 x 150 （装备 / 件）

击杀小怪可以概率获得乱属性水晶，可以在盖罗尔特处把 NM 获得的常风水晶分解为乱属性水晶（每次分解可获得 1~5 个水晶，由于分解概率是一次性计算的，而期望非平均分布，因此如果闲的没事也可以一个一个拆）。

只有19 以上的玩家完成 NM 暴风魔王——帕祖祖才可以获得帕祖祖的羽毛（金牌可获得 3 个），另外也可以使用乱属性水晶 x 300 兑换羽毛（营地内调查队的警卫员）。

恒冰之地

heading.anchorLabel

开启恒冰的禁地兵装同样需要先练级并完成恒冰之地全部的剧情任务。25 之后，可以从可露儿那里获得优雷卡以太壶，然后打等级高于自己的小怪的时候就可以获得以太（类似刷光），刷满之后可以从优雷卡恒冰之地 (X: 6.1, Y: 21.6)的试制魔晶炉那里提取出结冰乱属性水晶。以太壶最多可以存 9 条光，适当安排刷光计划，减少前往试制魔晶炉的次数。

恒冰除了完成 NM 可以刷光之外，还可以组队打高级怪（默认40 的小怪）刷光。初见的新人看到公屏里有刷光的组队进组就可以，推荐有元素补正的玩家做 T。另外也可以通过触发 NM 或者刷变异箱子来刷光（效率不如直接刷光高，但是可以有其他收益）。

NOTE：恒冰之地只有武器强化，没有装备相关内容。

恒冰合计：结冰乱属性水晶 x 31 + 恒冰水晶 x 500 + 娄希的冰片 x 5

参与 NM 并获得评价就可以获得恒冰水晶。只有34 以上的玩家完成 NM 苍蓝冰刃——娄希才可以获得娄希的冰片（金牌一次可以获得 2 片），另外也可以使用恒冰水晶 x 50 兑换冰片（营地内调查队的警卫员）。

涌火之地

heading.anchorLabel

完成涌火之地的武器强化需要先制作出一把恒冰武器，还需要合成一定数量的文理技能，可以使用文理系统网站记录文理技能。只做武器的话只需要合出 30 种文理技能即可，如果需要购买优雷卡元素防具，则需要合成 50 个文理技能。

名称及装等所需材料
元素武器 +1
375		记录过 10 种文理技能 + 涌火水晶 x 150
元素武器 +2
380		记录过 20 种文理技能 + 涌火水晶 x 200
涌火武器
385		记录过 30 种文理技能 + 涌火水晶 x 300 + 彭忒西勒亚的火种 x 5

涌火合计：涌火水晶 x 650 + 彭忒西勒亚的火种 x 5 （+ 爆炎乱属性水晶若干 #非必要，可不刷）

参与 NM 并获得评价就可以获得涌火水晶。只有49 以上的玩家完成 NM 炎蝶的女王——彭忒西勒亚才可以获得彭忒西勒亚的火种（金牌一次可以获得 3 个），另外也可以使用涌火水晶 x 50 兑换火种（营地内调查队的警卫员）。

获得涌火武器之后可以跟盖罗尔特对话获得优雷卡以太壶【火】，和恒冰一样刷光，提取出爆炎乱属性水晶，集齐 2 个水晶再找盖罗尔特可以为涌火武器添加副属性。副属性为随机词条 x 随机属性值，词条上限为 5 个，属性上限为 200 如果非常幸运地抽中 5 个 200 暴击，那么就会获得千暴武器。 每次刷新属性时获得的词条数量为当前词条数量 +0 或 +1（建议开出新词条就无脑覆盖，先把 5 个词条洗出来），属性都是随机的，相同属性会最终叠加。

由于现在优雷卡武器副属性完全不重要（除非需要在同步条件下挑战 70 级的副本内容），因此不刷光也没有问题。

另外记录过 50 种文理技能之后，可以在调查队的工匠处优雷卡涌火之地 (X: 15.4, Y: 23.8)使用涌火水晶 x 40 兑换元素防具（iLv380），这套防具可以在丰水之地升级为发光的元素防具。

丰水之地

heading.anchorLabel

50 且完成之前的剧情任务后，带着做好的涌火武器就可以为武器做最后升级了。

名称及装等所需材料
丰水武器
390		丰水水晶 x 50
丰水武器 +1
395		丰水水晶 x 100
新禁地兵装
400		丰水水晶 x 100
新禁地兵装最终形态
405		丰水水晶 x 100 + 水晶龙之鳞 x 5

丰水合计：丰水水晶 x 350 + 水晶龙之鳞 x 5

参与 NM 并获得评价就可以获得丰水水晶。只有59 以上的玩家完成 NM 水晶之龙——起源守望者才可以获得水晶龙之鳞（金牌一次可以获得 3 个）。

另外记录过所有 56 种文理技能之后，可以使用丰水水晶 + 元素防具（涌火兑换）获得元素防具 +1（iLv390）。

优雷卡武器及元素防具 +1 可以在开启兵武库后，使用兵武库内获得的优雷卡的断片 继续升级为带有优雷卡专属元素补正的装备，该元素属性补正仅在优雷卡内生效，如果无意挑战兵武库的话可以无视。
